# 페이지
 ## 주제
    - 행성파괴 시뮬레이터

 ## 파일종류
    - index.html
    - script.js
    - style.css
 ## 작동
  ### 회전
    - 마우스를 클릭하고 옆으로 돌리거나 하면 삼차원상에서 화면이 돌아간다. 그리고 이 감도는 왼쪽에서 설정할 수 있도록 한다.
  ### 게임 실행
    - 폭탄이나 레이저를 선택해서 행성의 특정 부분을 클릭하면 그 부분이 파괴되며 행성이 그부분이 파괴된 모양으로 바뀐다. 행성은 지구로 설정한다.
  ### 디자인
    - 검은색 배경에 별이 조금씩 찍혀있다. 그리고 중앙에 지구 모양이 있고 왼쪽에는 각종 설정들과 파괴할 수 있는 아이템을 가질 수 있게 한다.
  ### 기타
    - 모바일과 PC에 다르게 나와서 픽셀이 안깨지겠끔 동적서비스로 구축해라
